## 2026-04-27 - Optimize AnimatedBuilder with Static SweepGradients
**Learning:** In Flutter, recreating complex visual elements like `SweepGradient` shaders inside an `AnimatedBuilder`'s builder function causes expensive repaints and shader recompilations every frame. This codebase had multiple instances (e.g., `MeshRadar`, `BystanderRadar`) where the gradient's rotation was manually animated via shader parameters (`GradientRotation`) inside the builder.
**Action:** Always move static subtrees involving expensive shaders (like `Container`s with `SweepGradient` or `CustomPaint`s without dynamic data) out of the `AnimatedBuilder`'s builder function and into its `child` parameter. Apply visual transformations (like `Transform.rotate`) purely within the builder to rotate the already-rendered static child, avoiding costly widget and shader recreation.
