# Security Policy

## Supported Versions

We only provide security updates for the current major release of RoadSOS.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security and privacy are paramount for an emergency response application.

If you discover a vulnerability in RoadSOS, please **DO NOT** open a public issue. Instead, email us directly at `security@roadsos.io` or use the GitHub Security Advisory private reporting feature.

We aim to respond to all reports within 48 hours and will keep you informed of our progress towards a fix and announcement.
